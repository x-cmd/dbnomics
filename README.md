# dbnomics

**Economics, as plain URLs.** Macro knowledge pages built on [DBnomics](https://db.nomics.world) data — every chart is a [x-cmd draw](https://github.com/x-cmd/draw) URL: the data lives in the link, rendered as SVG. Open any chart's URL and you see its full parameters; paste it anywhere markdown images work.

> Module help (CLI params): [x-cmd.com/mod/dbnomics](https://x-cmd.com/mod/dbnomics) — `x dbnomics data <series>`, `x dbnomics align <a> <b> <c>`.
> 中文版: [docs/1-about/cn.md](docs/1-about/cn.md)（各页均有 cn/en）

## How the charts work

Each figure is `https://po6.sh/draw/echarts?d=<urlencoded ECharts option>` — an ECharts option in the URL, server-side rendered to a standalone SVG by [x-cmd/draw](https://github.com/x-cmd/draw). No JS runs on this page; the SVG is static, printable, and AI-readable (the option *is* the data).

To make your own: pick a series with `x dbnomics`, then hand the numbers to draw — or let your AI agent do it with the [draw skill](https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md).

## Data sources

IMF World Economic Outlook · BIS central bank policy rates — fetched via the [DBnomics API](https://api.db.nomics.world/v22), cached by the `x dbnomics` module. Annual series sliced to 2000–2024 (actuals); 2024 values are WEO estimates.
