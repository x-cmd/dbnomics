# 瓦格纳法则：政府为什么越长越大

瓦格纳法则（19 世纪德国经济学家）：随人均收入上升，政府支出/收入占 GDP 比重趋于上升 — 公共服务的需求收入弹性大于 1。图上 x=人均 GDP（对数感），y=政府收入 % GDP，路径从左到右是时间。

**判断**：中国是教科书级样本 — 人均 GDP 从 $951（2000）到 $12,969（2024），政府收入占比从 13.4% 翻倍到 26.4%：城市化、社保、基建的公共品需求随收入膨胀。美国路径几乎垂直（收入已高，占比稳定在 ~30%）：发达经济体的政府规模收敛 — 瓦格纳法则的后半段故事。
