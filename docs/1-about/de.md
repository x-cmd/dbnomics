# DBnomics und diese Seite

DBnomics (db.nomics.world) bündelt Zeitreihen von IWF, Weltbank, OECD, Eurostat, EZB, BIS und über 70 offiziellen Quellen in einer freien API. Diese Seite = **Volkswirtschafts-Wissen + Diagramme**: ein Makrothema pro Seite, jedes Diagramm eine **Klartext-URL, gerendert von x-cmd draw** — die Daten stecken im Link, KI-lesbar.

Daten aus der Shell (Modulhilfe: [x-cmd.com/mod/dbnomics](https://x-cmd.com/mod/dbnomics)):

```sh
x dbnomics data imf.us.gdp.growth
x dbnomics align imf.us.gdp imf.cn.gdp
x dbnomics alias
```

Datenstand: IWF WEO 2025 (inkl. Prognosen) · BIS-Leitzinsen (Jahresende). Alle Diagramme nutzen 2025 als letzten Wert.
