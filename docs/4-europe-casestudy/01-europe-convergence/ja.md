# 欧州の収束：キャッチアップは本物か

二百年前、リスボンの労働者はミュンヘンの労働者が得一分の何分も稼げなかった。今、その差ははるかに縮んだ。よく使われる期待はこうだ――出発点の低い経済ほど速く成長し、やがて上位の水準に追いつく。横軸は2000年の人均GDP、縦軸は2000–24年の平均成長率。EU成员国ごとに一点（EUの27か国のうち18か国）。

**判断**：収束は全体として成り立っている――東欧（ポーランド、ルーマニア、スロバキア）は低い起点から年 4–5% で成長し、じりじりと差を縮めてきた。しかし左側の裕福なクラブは分かれている：ギリシャとイタリアは同じ低成長の帯にあり、収束では説明できない南の停滞だ。あれは構造と債務の話であって、キャッチアップの話ではない。
