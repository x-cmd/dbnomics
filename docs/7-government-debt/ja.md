# 政府債務

政府債務の対 GDP 比は持続可能性の中核指標；マーストリヒト条約は 60% の基準線（赤破線）を設けた — 硬い上限ではないが r−g が悪化するとリスクは急騰する。日本 ~250% は保有者構造と低金利で安定；ギリシャは危機の標本；米国は 120% 超で平時に上昇。
