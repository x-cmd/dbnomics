# 经常账户

经常账户 = 货物与服务贸易 + 初次收入 + 转移（% GDP）。顺差 = 对外净放贷，逆差 = 净借入 — 跨期借贷的镜像。德国 6%+ 是欧元区内部争议点；中国收敛后稳定在 1–2%；美国 ~3% 逆差靠美元地位长期融资（红色柱）。
