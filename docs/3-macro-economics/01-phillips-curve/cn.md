# 菲利普斯曲线：通货膨胀与失业的取舍

菲利普斯曲线是经济学里最古老的政策规则：通货膨胀和失业反向变动，所以政府可以挑一个让自己多受着。这里每条线是一个国家从 2000 年到 2025 年的路径——x 轴是通货膨胀，y 轴是失业率——不是拟合出来的曲线。

**判断**：美国画出一个完整的圈——2020 年疫情坑（低通胀、高失业）→ 2021–23 年转向 8% 通胀、失业率仍在 4% 以下（过热）→ 2024 年回到 3.0% 通胀和 4.1% 失业。加息在不引发衰退的情况下压死了通胀：这是 40 年来最平稳的一程。中国处在低通胀的角落（约 0.4% 通胀）——这不是这条曲线的胜利，只是需求疲弱。

欧元区是第三条线：2021–23 年的能源冲击把通胀推到 8.4% 的峰值，而失业率一路降到 6.5%——这是供给冲击的形状，和美国的需求路径不同。
