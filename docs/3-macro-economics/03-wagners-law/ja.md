# ワグナーの法則: なぜ政府は膨らみ続けるのか

私立学校に払えるようになったはずの家族が、最後は公立のよい学校にお金を出すのはなぜだろう。ワグナーの法則は、19 世紀のドイツ人経済学者にちなむ: 人が豊かになるほど公共サービスを多く求めるようになるので、政府は経済のより大きな割合を占める。ここでは横軸が一人当たり GDP、縦軸が政府収入の GDP 比で、各経路は時間を左から右へ進む。

**判断**: 中国は教科書的なケースである——一人当たり GDP が $951(2000 年)から $12,969(2024 年)へ増える一方、収入比は 13.4% から 26.4% へ倍増した: 都市化、社会保障、インフラがすべて所得とともに膨らむ。アメリカの経路はほぼ垂直である——すでに豊かで、比率は 30% 前後で横ばい。豊かな経済では政府の規模が収束する。これがワグナーの物語の後半である: 曲線は平坦になる。
