# 瓦格纳法则：政府为什么一直变大

为什么终于攒够钱送孩子上私立学校的家庭，最后还是愿意为一所好公立学校掏钱？瓦格纳法则——得名于 19 世纪的一位德国经济学家——说这不是口味的怪癖。人越有钱，越想要更多公共服务，于是政府就从经济里切走更大的一块。这里 x 轴是人均 GDP，y 轴是政府收入占 GDP 的份额；每条路径都随时间从左往右走。

**判断**：中国是教科书式的案例。人均 GDP 从 $951（2000 年）涨到 $12,969（2024 年），收入份额翻了一倍，从 13.4% 到 26.4%。城镇化、社会保障和基础设施都跟着收入一起胀大。美国的路径几乎是垂直的——本来就富，份额在 30% 上下横着走。富裕经济体之间政府规模会趋同，这是瓦格纳故事的另一半：曲线会走平。
