# 奥肯法则：增长如何换回就业

奥肯法则是一条久经考验的经验规则：当增长低于正常水平时，失业率大约会上升一半。这里的 x 轴是实际增长，y 轴是失业率的同比变化——落在右下方的点意味着增长在消化失业，落在左上方的点意味着衰退在推高失业。

**判断**：美国那团点云紧贴一条干净的下行斜线——这条法则 25 年都成立，2010 年代的扩张靠 2% 以上的增长啃掉了失业；2020–21 年那两个离群点是封控开关被按下造成的。中国的点云整体向上、向右移动：增长与就业之间的联系变弱了，因为一个处在结构转型中的国家，不再把增长一一转化为编制。

欧元区的斜率更平：僵化的劳动力市场缓冲了增长与就业之间的联系。
