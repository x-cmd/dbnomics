# 奥肯定律：增长怎么换来工作

你所在城市的工厂改成夜班、开始招人，街坊邻居会察觉到吗？奥肯定律说会，而且大致说得出会多少。这条规则是一条经验口诀，但战绩很长。增长低于正常水平时，失业率上升的幅度大约是它的一半。这里 x 轴是实际增长，y 轴是失业率的同比变化。落在右下角的点意味着增长在消化失业，落在左上角的点意味着衰退在把失业推高。

**判断**：美国那团点云紧贴一条干净的下降斜线，而且守住了 25 年。2010 年代那轮扩张用 2% 以上的增长啃掉了失业。唯独跑偏的两个点是 2020–21 年，那是封城的开关被按下，不是定律失灵。中国的点云整体往右上移。增长和就业之间的联系在这里更松，因为一个处在结构转型中的国家，不再把增长换算成编制。

欧元区的斜率更平：僵硬的劳动力市场把增长和就业之间的联系垫住了。欧洲也正因如此，才能一边有点增长，一边还丢一点失业。
