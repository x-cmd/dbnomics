# 贝弗里奇曲线：职位空缺与失业

贝弗里奇曲线把两个通常反向变动的数字连起来：职位空缺（没人填补的岗位）和失业（没有工作的人）。空缺多、失业低就是繁荣；反过来就是萧条。当曲线向外移动时，两者就对不上了——岗位空着，人却还失业。

**判断**：蓝色路径 2001–2019 沿着一条稳定的曲线下滑（危机时向下，扩张时向上）。红色路径 2020–24 是教科书案例：疫情把曲线**向外**推——2021–22 年职位空缺率超过 7%，而失业率反而下降（大辞职打乱了匹配）——接着 2023–24 年空缺下降，失业率却没有明显上升，也就是说这是沿一条更高的新曲线回归正常，而不是回到旧曲线上。剩下的那段外移，就是疫情给美国劳动力市场留下的永久疤痕。
