# 贝弗里奇曲线：职位空缺与失业

一座城市怎么会有工厂招不到人，同时又有人找不到工作？贝弗里奇曲线把两个通常反向变动的数字连在一起：职位空缺（没人填的坑）和失业（没有工作的人）。空缺多、失业低，是繁荣；反过来就是萧条。当曲线向外移动时，两者就配不上了——岗位空着，人却还失业。

**判断**：美国没有回到从前。蓝色的 2001–2019 那条路径沿着同一条曲线滑行，危机时往下，扩张时往上。红色的 2020–24 那段是教科书案例。疫情把曲线向外推了一把：2021–22 年空缺率超过 7%，失业率却还在往下走，因为大辞职潮把岗位和人对接的环节弄断了。接着 2023–24 年空缺率回落，失业率没怎么涨。这是沿着一条更高的新曲线回归常态，而不是回到旧曲线。那道留下的外移，就是疫情给美国劳动力市场留下的疤。
