# 拉弗曲线：找不到的那座山

老板说，只要多招人就不扣你工资。你会挑眉：少发钱、多招人，钱从哪儿来？拉弗曲线讲的就是这个故事：税率减到某个程度之后，降税反而能把税收自己养起来，因为人们不再少干活、不再藏收入、不再把家安到别处。要把它画准，你得拿到**税率**（你拧的那个旋钮）。可公共数据库里大多只有**税收占 GDP 的比重**（最后的结果）。所以这张图只能用手上有的东西：横轴是政府收入占 GDP 的比重（2000–25 年平均），纵轴是同期实际增长率的平均值，G20 每个经济体一个点。

**判断**：从沙特阿拉伯的 ~20% 到法国的 ~45%，**看不见任何一座山**。低税的沙特和墨西哥，与高税的法国和德国，落在同一片增长区间里。拉弗曲线在真实数据里不出现：真正拉动增长的是制度、人的能力和经济周期，这三样都把税收占比的作用压了下去。这条曲线也许真的在极高税率处存在，只是真实经济体从不住在那两个极端上。
