# 拉弗曲线：没人找到的那座山

拉弗曲线是那个著名论点：减税可以自己养活自己——税率过了某个水平，再加税反而会减少财政收入，因为人们不干了、藏起收入或者搬走。要把它画准，需要**税率**（旋钮）；而公共数据库里大多只有**财政收入份额**（结果）。所以这张图只能用现有的东西：x 轴是政府收入占 GDP 的份额（2000–25 年均值），y 轴是同期平均实际增长，G20 每个经济体一个点。

**判断**：从沙特阿拉伯的约 20% 到法国的约 45%，整个区间里**看不到山**——低税的沙特阿拉伯和墨西哥，与高税的法国和德国，处在同一个增长区间里。拉弗的山在真实数据中不出现：增长由制度、技能和周期驱动，它们的分量远远压过财政收入份额。这条曲线也许在极端税率下存在——只是真实经济体不生活在极端上。
