# ラッファー曲線：誰も見つけない山

「正社員を雇うなら、給料の天引きはやめるよ」――あなたの眉はぴくりとします。給料は減るのに雇用は増える。さて、その金はどこから来るのか。ラッファー曲線が語るのはこの物語です。減税は自らを賄うことができる、と。ただし税率がある水準を超えると、人は働くのをやめ、収入を隠し、国を去る。だから理論上は山が存在する。この図が使うのは手元にあるものだけだ：横軸は政府収入のGDP比（2000–25年の平均）、縦軸は同期間の実際の成長率の平均、G20の一経済体につき一点。

**判断**：サウジアラビアの ~20% からフランスの ~45% まで、**見える山はどこにもない**。低税率のサウジアラビアとメキシコが、高税率のフランスやドイツと同じ成長の帯に属している。ラッファー曲線は実データに現れない。成長を動かしているのは制度、人的能力、そして景気循環であり、この三つはいずれも歳入の比率を押し潰すほど大きい。曲線自体が存在するのは極端な税率のときかもしれない。現実の経済は極端な場所には住まない。
