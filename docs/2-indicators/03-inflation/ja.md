# インフレ

給料明細から逃れられない数字があります。インフレとは、平均的な日用品のかごが時間とともに高くなっていくことで、ここでは消費者物価指数（CPI、つまり毎年同じかごに張られる値札）の前年比上昇率として表します。経済学で最も実感できる数字で、給料が何を買うかを決めます。

2021–23 年の上昇は 3 つのことが同時に起きました。サプライチェーンの断裂、エネルギー高、そしてパンデミック中に緩すぎた政策。US と euro area は 8–10% でピークをつけました。Türkiye が極端なケースで、60%+、崩れた通貨に引っ張られた形です。Japan は数年目標を下回りました——デフレーションの罠です。みんな安い価格を待ち続けるから価格は上がらない。China がほぼゼロなのは需要の弱さで、力強さではありません。ひとつ区別しておいてください。*disinflation*（物価上昇が鈍ること）は *deflation*（物価が実際に下がること）ではありません。
