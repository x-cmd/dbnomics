# 通货膨胀

通胀是总体物价的持续上涨（CPI 同比）。2021–23 全球通胀潮由供应链、能源与宽松政策叠加引爆 — 美欧峰值 8–10%；Türkiye 是极端样本（汇率危机驱动的 60%+）。日本长期低于目标是通缩陷阱的镜像；中国接近零反映需求不足。通胀回落 ≠ 降价，只是涨得慢了。
