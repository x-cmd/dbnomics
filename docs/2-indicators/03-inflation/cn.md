# 通货膨胀

有一个数字躲不过你的工资单：通胀就是同一篮子日用品一年比一年更贵——这里用的是居民消费价格指数（CPI，也就是同一篮子东西每年的价签）的年度涨幅。它是经济学里体感最强的数字：它决定一份工资能买到多少。

2021–23 那波上涨是三件事同时发生：供应链断了、能源变贵，还有疫情期间过于宽松的政策。US 和 euro area 见顶在 8–10%；Türkiye 是极端案例（60%+，被崩塌的货币拖上去的）。Japan 多年低于目标——这就是通缩陷阱：人人都等着更便宜，价格于是涨不上去。China 接近零反映的是需求疲弱，不是强势。有个区别要记住：*disinflation*（涨价变慢）不等于 *deflation*（价格真的在跌）。
