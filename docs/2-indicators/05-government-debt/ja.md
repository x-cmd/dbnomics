# 政府債務

ある国の請求書が台所のテーブルに積み重なっている情景を想像してほしい。政府債務の GDP 比は、その国が一年間につくり出したもののうち、すでに誰かに約束してしまった分だ。そして **マーストリヒト** の 60% という参照線（EU がユーロ圏加盟国のために定めたガイドライン）は、ダッシュボードの警告灯であって壁ではない。越えても、その場では何が起きるわけでもない。何年もう視無視すれば、道は次第に高くつく。

**判断**: その請求書が支払えるかどうかを決めるのは r − g だ。支払っている金利（r）と、経済自身の成長速度（g）の差である。支払っている利子が経済成長より安いなら、支出を続けながら債務比率はじりじり下がる。逆に高いなら、債務は国より速く膨らむ。日本は GDP の 250% 近くにありながら安定している。債務は低金利で保有している国内の貯蓄者が握っているからだ。ギリシャが危機のケースである。アメリカは 120% を超えたまま、平時でも上昇を続けている。図の赤い線が 60% の参照線だ。十四の経済のうち、その線の下に残っているのは三つだけ。
