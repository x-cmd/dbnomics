# 政府债务

想象一个国家的账单堆在厨房桌上。政府债务占 GDP 的比重，就是这个国家一年生产出来的东西里，有多少已经许诺给了别人。而 **马斯特里赫特** 60% 这条参考线（欧盟为欧元区成员设定的指引），是仪表盘上的一盏警示灯，不是一堵墙。越过它，当时什么也不会发生。年年无视，路才会越走越贵。

**判断**：决定这笔账还得还得起的，是 r − g。也就是你付的利率（r）和经济自己长出来的速度（g）之间的差。付的利息比经济增长便宜，债务率就算你继续花钱也会慢慢往下走。付得更贵，债务就比国家长得更快。日本在 GDP 的 250% 附近却稳得住，因为债务握在低利率的国内储蓄者手里。希腊是危机案例。美国超过 120%，而且在和平时期还在往上爬。图上那条红线就是 60% 参考线。画出来的十四个经济体里，只剩三个还在它下面。
