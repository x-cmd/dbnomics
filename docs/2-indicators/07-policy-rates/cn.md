# 政策利率

向银行借一晚过夜钱要付的价钱，就是政策利率。全国每张房贷、每个储蓄账户、每套房价都靠这一个数字撑着。它还定住了汇率，也渗进股票值多少钱。动一下这个数，效果过几个月就会落到你的工资条上。

**判断**：过去十年可以分成三幕。第一幕是金融危机之后的慢慢回归常态（2015–19）。第二幕是 2022–23 那场对抗通胀的猛加息，Fed 从 0 加到 5.5%。第三幕是最后一次退出：2024 年日本银行离开超宽松政策，结束了一场 30 年的实验。ECB 跟着 Fed 走，但步子更小。留意 BoJ 那条线的形状。它常年待在零以下，2024 年才转正。出口就写在这条线离开地下室的那一刻。
