# 政策金利

銀行から一晩だけお金を借りるときに払う値段が、政策金利のことだ。国中の住宅ローン、預金口座、住宅価格、そのすべてがこの一つの数字に寄りかかっている。為替レートもここで決まり、株価の値にも影響する。この数字を動かせば、数か月後にあなたの給料帖まで届いてくる。

**判断**: 過去 10 年は 3 幕として読める。第 1 幕は金融危機後の、ゆっくりとした正常への帰還（2015–19）。第 2 幕は 2022–23 のインフレ対策の大幅な加息、Fed が 0 から 5.5% まで上がったこと。第 3 幕は最後の出口——2024 年に日本銀行が超宽松政策から抜け、30 年の実験に終止符を打った。ECB は Fed にならい、だが歩幅は小さかった。BoJ の線の形に注目してほしい。長くゼロ近辺の水準を過ぎ、2024 年で初めて正になる。出口は、この線が地下を離れた瞬間に見える。
