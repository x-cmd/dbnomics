# 经常账户

你所在城市的每家店里都卖着外国货，而你的每一份工资也都买着外国货。经常账户就是这笔账的流水。它把一国卖给世界的东西减去从世界买回来的东西，加总起来。再把在国外挣到的收入和收到的转移支付添上去，全部换算成占 GDP 的比重。有盈余，意味着这个国最后是借钱给别人。出现赤字，意味着最后是向别人借钱。

**判断**：盈余不是奖杯，赤字也不是病。两者都只是一个国家「存下来的钱」和「投出去的钱」之间落差的镜子。德国 6%+ 的盈余是欧元区内部一个摩擦点：钱老是堆在同一个角落。中国稳定在 1–2%。美国常年挂着约 3% 的赤字，而且能一直融下去，因为它是用本币借的钱。图上的红柱就是赤字那一侧。美国、俄罗斯和 Saudi A. 站在这一边。
