# 经常账户

经常账户把一个国家卖给世界其他部分的东西减去从它们买来的东西，再加上在国外挣到的收入和收到的转移支付——以占 GDP 的份额表示。顺差意味着这个国家是世界的净贷款方；逆差意味着它是净借款方。

顺差不是奖杯，逆差也不是病——两者都只是「一国存的钱」与「一国投的钱」之间落差的镜子。德国 6% 以上的顺差是欧元区内部的一个摩擦点（钱不断堆在一个角落里）；中国稳定在 1–2%；美国有约 3% 的逆差，而且能无限融下去，因为它是以本币借款。红色柱子标出每个经济体站在哪一边。
