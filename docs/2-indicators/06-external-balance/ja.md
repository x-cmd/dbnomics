# 経常収支

街のどの店にも外国製の商品があり、あなたの賃金も外国製の商品を買うに使われる。経常収支は、そのやり取りをまとめた帳簿だ。国が世界に売った分から世界から買った分を引き、海外で得た収入や移転支付を加え、GDP 比で表したものがそれだ。黒字なら、その国は最終的に世界に対して貸す側になる。赤字なら、最終的に世界から借りることになる。

**判断**: 黒字はトロフィーではなく、赤字は病でもない。両者はただ「国が蓄財した額」と「国が投資した額」の差を映した鏡にすぎない。ドイツの 6%+ の黒字はユーロ圏内部の摩擦点だ。資金が片側に集まり続けるからだ。中国は 1–2% で落ち着いている。アメリカは ~3% の赤字を抱えつつ、自分の国の通貨で借りているがゆえに、明目張胆とはいかずとも長く借金を続けることができる。図の赤い棒が赤字側だ——アメリカ、ロシア、Saudi A. がそこにいる。
