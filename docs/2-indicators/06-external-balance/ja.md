# 経常収支

経常収支は、その国が世界に対して売るものから買うものを差し引き、さらに海外で得た所得と转移支払いを足し、GDP 比で表したものである。黒字はその国が世界への純貸し出し者であること、赤字は純借り入りを意味する。

黒字はトロフィーではなく、赤字は病ではない——どちらも、その国の貯蓄と投資の差の鏡像にすぎない。ドイツの 6% 超の黒字はユーロ圏内部の摩擦点である(資金が片側に集まり続ける)。中国は 1–2% で落ち着き、アメリカは約 3% の赤字を自国通貨で借りられる限り永続的に賄える。赤い棒は各経済がどちら側にいるかを示している。
