# 経常収支

経常収支 = 財貨・サービス + 第一次所得 + 移転（対 GDP 比）。黒字は対外純貸付、赤字は純借入 — 国際貸借の鏡像。ドイツの 6% 超はユーロ圏内の摩擦点；中国は 1–2% で安定；米国の ~3% 赤字はドル地位で恒常的に調達（赤い柱）。
