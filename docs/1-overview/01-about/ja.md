# 見える経済学

このサイトのグラフは一つ残らずリンクです。クリックすれば図が開き、リンクを読めば背後にある数字が手に入ります。データは URL の中に埋め込まれているので、AI エージェントもそのまま読めます。扱われているのは、あなたの一週間を左右する主題——雇用、価格、成長、負債、そして世界最大の経済圏が実際に何をしているか——です。

サイトは六つのセクションで構成され、一方向に読めます。**何を見るか → それを縛る法則は何か → 一つの経済圏を近くで見るとどんな感じか**。指標（GDP、成長、インフレ、失業率、負債、対外収支、経常収支、政策金利、人口と貯蓄）· マクロ経済学（五つの法則：フィリップス、オークン、ヴァーグナー、ベヴァリッジ、ラファー）· そして三つのケーススタディ——ヨーロッパ、アメリカ、中国。

どこから読めばいいか迷っていますか。論じられることの多いのはこの六つのページで、それぞれがあなたがすでに抱いている問いに答えます。

**三つの経済圏、三つの主張。**アメリカ、ユーロ圏、中国を同じ目盛りで並べると：誰の労働市場が窮し、誰の価格が穏やか、誰がまだ成長し、誰が最も借りている。人それぞれ意見がある。ここではデータを提示する——そしてデータが結論を出さない部分も。

**あなたの仕事と買い物カゴは、同じシーソーの上に乗っている。**フィリップス曲線はマクロ経済学で最も古い法則です。価格が上がると求人減り、政府はどちらかを優先せざるを得ません。アメリカはいま、四十年来もっともなめらかな一版を経ました。

**ある都市が誰も望まない仕事と、必要としている人の両方を持つのはなぜ？**ベヴァリッジ曲線は求人と失業を突き合わせます。通常は右下に傾きますが、パンデミックの間に外側へ曲がり、その後は完全には立て直していません。

**六十年間、すべてのアメリカ不況を事前に示した唯一の指標。**10 年物米国国債の利回りが 3 か月物を下回ると、市場は中央銀行の利下げを予想しています——そしてそのあとには不況が続きます。2022 年と 2023 年に反転しました——2025 年には再び急カーブに戻りました。

**五十の経済圏、ひとつのクレジットカード。**ワシントンは、通貨を共有するだけでほぼ他は何も共有しない州に対して、一つの財政政策、一つの連邦準備制度地図、一つの破産裁判所を敷いています。ニューヨークとミシシッピの差は 2.2 倍で、24 年の「収束」がそれを埋めることはできませんでした。

**一つの国、二つの経済。**中国の沿岸では、工業の町が北方の県一つ分を丸ごと上回るほど稼げます。差は 11.7 倍から 4.3 倍に縮まりました——けれど人は逆向きに動きました：広東は 2000 年のときより 5500 万人も増えました。

ここでグラフを読むには：クリックするだけです。URL *こそ* がグラフで、数字は中にそのまま見えます。データはコマンド一つで届きます（モジュールのヘルプ：[x-cmd.com/mod/dbnomics](https://x-cmd.com/mod/dbnomics)）：

```sh
x dbnomics data imf.us.gdp.growth
x dbnomics align imf.us.gdp imf.cn.gdp
x dbnomics alias
```

データの版：IMF の *World Economic Outlook*（2025 年版、予測込み）と BIS の政策金利。州・省のページは OECD の地域データベースを使っています。すべてのグラフの最新の年は 2025 年です。**クイックスタート**：グラフの URL を任意のドキュメントに貼り付けるか、[draw skill](https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md) を AI エージェントに指定して、アメリカと中国の GDP をグラフ化させてください。
