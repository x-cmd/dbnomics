# 看得见的经济学

这个网站上的每一张图都是一个链接。点开它，图就出来了；读那个链接，你就拿到背后的数字——数据就写在 URL 里面，所以 AI 智能体也能读它。这里谈的正是决定你这一周过得怎样的那些事：就业、价格、增长、债务，以及地球上最大的经济体究竟在做什么。

网站分为六个部分，顺序是单向递进的：**看什么 → 什么规律在约束它 → 一个经济体近距离长什么样**。指标（GDP、增长、通货膨胀、失业率、债务、对外收支、经常账户、政策利率、人口与储蓄）· 宏观经济学（五条规律：菲利普斯、奥肯、瓦格纳、贝弗里奇、拉弗）· 以及三个案例研究——欧洲、美国、中国。

不知道从哪儿开始？这六页就是人们争论最多的内容——每一页都回答一个你本来就有的问题。

**三个经济体，三种论调。**把美国、欧元区和中国放在同一组刻度上：谁的就业市场最紧，谁的价格最平稳，谁还在增长，谁借得最多。人人都有看法；这里给出的是数据——以及数据本身无法下结论的地方。

**你的工作和你的购物篮坐在同一架跷跷板的两端。**菲利普斯曲线是宏观经济学里最老的规律：价格涨上去，岗位就变少，于是政府必须挑一个自己更想要的。美国刚刚走过了四十年来最平顺的一个版本。

**一座城市怎么会有人人都不要的岗位，又有人找不到一份工作？**贝弗里奇曲线把职位空缺和失业放在一起看。它通常是向下倾斜的；疫情让它向外弯折，此后一直没有完全挺直。

**六十年来，每一次美国衰退都被这个指标提前说中。**当 10 年期国债收益率跌到 3 个月期之下，市场是在押注央行会降息——随后通常就跟着衰退。它在 2022 年和 2023 年出现倒挂；2025 年重新变陡。

**五十个经济体，一张信用卡。**华盛顿对那些共用一种货币、其余几乎什么都不一样的州，实行一套财政政策、一张美联储地图、一套破产法。纽约和密西西比相差 2.2 倍，24 年的「收敛」也没能把这个差距关上。

**一个国家，两种经济体。**在中国沿海，一座工厂镇可以比北方一整个省挣得还多。差距从 11.7 倍缩到 4.3 倍——但人往另一个方向走了：广东比 2000 年时多了 5500 万人。

在这里怎么看图：点它。URL *就是*图表本身，数字明明白白写在里面。数据近在一条命令之外（模块帮助：[x-cmd.com/mod/dbnomics](https://x-cmd.com/mod/dbnomics)）：

```sh
x dbnomics data imf.cn.gdp.growth        # 单序列
x dbnomics align imf.us.gdp imf.cn.gdp   # 多序列对齐
x dbnomics alias                          # 预置别名表
```

数据口径：IMF 的 *World Economic Outlook*（2025 年版，含预测）和 BIS 的政策利率；州与省页面用的是 OECD 的地区数据库。每张图都以 2025 年为最新年份。**快速上手**：把任意一个图表 URL 贴进文档，或者把这个 [draw skill](https://raw.githubusercontent.com/x-cmd/draw/main/SKILL.md) 指给一个 AI 智能体，让它把美国和中国的 GDP 画成图。
