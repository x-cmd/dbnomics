剩下的部分按一条线读:先看什么数,再看什么规律把它绑住,最后看某个经济体长什么样。词汇在指标区——GDP、通胀、失业、债务、利率、人;发动机在宏观经济学区,那里有五条至今还在互相吵架的定律;然后是三个案例:欧洲、美国,和从里面看的中国。[→ 2025 仪表盘](../../1-overview/02-macroeconomic-outlook/cn.md)

每一张图都是一个 URL,可以直接贴进任何文档——SVG 是静态的、可打印的,数字就写在链接里。数据也只差一条命令(模块帮助:[x-cmd.com/mod/dbnomics](https://x-cmd.com/mod/dbnomics)):

```sh
x dbnomics data imf.us.gdp.growth         # one series
x dbnomics align imf.us.gdp imf.cn.gdp    # multi-series, aligned
x dbnomics alias                           # preset alias table
```

**数据**:IMF《世界经济展望》(2025 年版)· 美国劳工统计局 · BIS 政策利率 · OECD 区域数据库(美国各州、中国各省)。所有图以 2025 年为最新一年。**复现**:`x dbnomics data imf.us.gdp.growth`
