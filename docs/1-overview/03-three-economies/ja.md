# アメリカ、ヨーロッパ、中国：三つの経済圏、三つの主張

三つの大経済圏のどれが勝っているかについて、人は誰しもの意見を持っています。問題は、「勝つ」が問い方によって意味を変えるということにあります——そしてグラフは毎回ちがう答えを返します。アメリカ、ユーロ圏（ユーロを使う二十の EU 加盟国）、中国を同じ目盛りに並べると、議論はスローガンではなくなります：誰の労働市場が窮し、誰の買い物カゴが穏やか、誰がまだ成長し、誰が最も借りているか。

**第一：雇用。**ユーロ圏は世紀の終わりを、人口の 9.1% が仕事をしていない状態で迎えました——アメリカの 4.0% の二倍以上です——そして 2013 年には 12.1% に達し、系列中の最悪の点に。アメリカは、その間 2019 年に 3.7% を記録しました：先進経済圏が経験した中でもっとも窮した労働市場です。中国の公式値は 5.1%——しかし引用の前にその線を見てください：都市労働者を対象とした調査であり、この系列は 2017 年に始まったものです。季節労働者にも、仕事が見つからない卒業生にも何も語っていません。ヨーロッパとアメリカの差は実在しますが、中国を真ん中に置くあの数字は、三つのうち最も当てにならない数字です。

**第二：買い物カゴ。**2021–23 年のインフレの波はアメリカ（2022 年に 8.0%）とヨーロッパ（8.4%）を直撃し、中国（2.0%）にはほとんど触れませんでした。2023 年には中国がただ一つの異例でしたが、理由はまさに逆でした：消費者価格は 0.2% しか上がらず、中国の問題はインフレではなくインフレの不在であり、2023–24 年の「デフレーション」騒動は実際には需要の弱さへの騒動でした。今や三者とも目標に近づいています——アメリカ 1.9%、ユーロ圏 2.0%、中国 1.7%。

**同じ4つの論争、1つの図に。** レーダーチャートは4つのメーターを4本の軸に置き換えます。各軸は3つの経済体のうち最高値と最低値の間で目盛りが取られ、100 はそのメーターでのリーダー、0 は後れ取りを表します。また、どの軸も「多いほどよい」方向を向き、失業率が低いほど、2% の目標に近いほど、成長が速いほど、負債が少ないほど、ということです。面積ではなく形を読んでください。アメリカは雇用では尖り、財政の余力では穴が開いています。失業率は 4.4% で、ユーロ圏の 6.4% と対し、負債は 124% で、ユーロ圏の 88% と対します。ユーロ圏は真中に水平に伸びる線です。物価でも財政の余力でもトップ、雇用でも成長でも最下位――真上から見た「波乱も成長もない」という姿そのものです。中国はその鏡像です。成長では満点で、2023-25 年は年平均 4.9% に対し、アメリカは 2.6%、ユーロ圏は 0.8% でした。物価はほぼゼロです。1.7% のインフレは、2% の目標との距離が他の2つよりどちらも遠いためです。雇用（5.1%）と負債（94%）は、地味に遜色ない水準にあります。各経済体はどれか1つのメーターではチャンピオン、別のメーターでは敗者です。だからこそ、どのスコアボードでもこの論争に決着をつけることはできません。
