# 菲利普斯曲线：通胀与失业的交换

菲利普斯曲线假说：通胀与失业负相关 — 政策在两者间取舍。图上每条线是一国 2000–2025 的年度路径（x=通胀，y=失业），不是拟合曲线。

**判断**：美国路径画出了一个完整的环 — 2020 疫情深坑（低通胀高失业）→ 2021–23 右移（8% 通胀 + 4% 以下失业的过热）→ 2024 回落（3% / 4.1%）：加息压通胀没有付出衰退代价，是 40 年来最理想的菲利普斯路径。中国停在左下角（低通胀 ~0.4% + 温和失业）：不是曲线胜利，是需求不足的另一个名字。

欧元区是第三条样本线:2021-23 能源冲击推高通胀(峰值 8.4%)而失业持续下行至 6.5 — 供给型通胀与需求型的美国路径形状不同,2024-25 同样无衰退回落。
