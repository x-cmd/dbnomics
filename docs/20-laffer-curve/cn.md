# 拉弗曲线：找不到的那座山

拉弗曲线断言:税率超过某点后,再提高反而减少税收 — 政策含义是"减税自付"。它需要**税率**(扭曲的边际),而公开数据库里只有**税收占比**(结果)。图上 x=政府收入占 GDP(2000-25 均值),y=同期年均增速,G20 十五国每点一国。

**判断**:横跨沙特 20% 到法国 45% 的区间,增速与税收占比**看不出任何山峰** — 低税的沙特/墨西哥与高税的法国/德国落在同一增长带里。真实数据里找不到拉弗的山:决定增长的变量(制度、人力资本、周期位置)远比税收占比响。曲线本身可能存在,但只在税率极端处才弯 — 而现实经济体不生活在极端处。
