# ラッファー曲線：見つからない山

ラッファー曲線は「税率がある点を超えると、さらに上げると税収が減る」と主張する。必要なのは税率だが、公開データにあるのは税収占比(結果)のみ。x=政府収入の GDP 比(2000-25 平均)、y=同期の平均成長率、G20 各国。

**判断**:サウジ ~20% からフランス ~45% まで、**山はどこにも見えない** — 低税国と高税国が同じ成長帯に並ぶ。現実データにラッファーの山はない:成長を決めるのは制度・人的資本・景気であり、税収占比よりはるかに大きい。曲線は極端な税率域にのみ存在するのかもしれないが、現実の経済は極端には生きていない。
