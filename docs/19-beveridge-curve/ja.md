# ベバリッジ曲線：空席と失業

ベバリッジ曲線:空席率と失業率は逆相関。曲線の外側への移動はマッチング効率の悪化を意味する。

**判断**:青の経路(2001-19)は安定した曲線に沿う;赤の経路(2020-24)は教科書的事象 — パンデミックが曲線を外側へ押し出し(2021-22 は空席 7%超)、2023-24 の正常化は旧曲線ではなく**より高い新曲線**の上で起きている。この残留シフトが米労働市場に残した永続的な傷である。
